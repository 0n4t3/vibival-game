# vibival-game
*Warning: this game is vibe coded. Not "some functions are unreviewed" vibe coded, or even "AI wrote the code but I micromanaged it" vibe coded. The game has a lot of human input, but it's all in the prompts, no human ever touched the code (outside of the game engine and dependencies, which - to be fair - is probably the reason it runs as well as it does).*

The game is far from finished, just like this readme.

If you'd like to try it, [playing the web version](https://0n4t3.github.io/vibival-web-client/) is probably your best bet. Linux and Android builds coming soon-ish, Windows likely to follow.
