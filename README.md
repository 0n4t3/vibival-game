# vibival-game
*Warning: this game is vibe coded. Not "some functions are unreviewed" vibe coded, or even "AI wrote everything line by line but I micromanaged it" vibe coded. The game has human input, but it's all in the prompts, no human ever touched the code (outside of the game engine and dependencies, which - to be fair - is probably the reason it runs as well as it does).*

## About
Vibival is a survival game, set in a vaguely carboniferous coal swamp. It’s a slow and grounded game, if that makes any sense. There’ll be no epic boss battles or megastructures to construct, you’ll probably be too busy cleaning a bite to keep it from getting infected because that stupid bug just bit you again, or digging up fern tree roots because you’re still low on greens.

If you'd like to try it, [playing the web version](https://0n4t3.github.io/vibival-web-client/) is probably your best bet. Linux and Android builds coming soon-ish, Windows likely to follow. There’s a [guide here](https://github.com/0n4t3/vibival-game/blob/main/docs/README.md) if you want to read it.

#### Progression
Progression isn’t entirely linear, and from the first time you play it to when you delete the world because *that stupid bug just bit you three times in a row*, you’ll still be spending time gathering food and trying to fetch water without being eaten by a swamp predator. Crafting is done in a 3D environment, and most items are stored in physical piles in the world instead of in containers.

Though there’s something of progression:

**1: game start.** Run around, try to find some food, and risk drinking the swamp water if you don’t find some clay in time to make a pot to boil water in. Probably get jump scared by a giant amphibious predator. Knap a few basic tools, snatch an ember from an existing fire to make your own, and survive the first night. Chase down a small animal yelling *get in my belly.* Make yourself a frond sack to increase your carry capacity.

As time goes on you’ll be able to do a bit more. Make a mattok to start replanting vegetation, and an axe to cut down trees. Find out what happens when you try to distract a large predator by throwing a stone, only to hit the directly instead of throwing one next to it. Learn that sleeping is the only way to have a permanent save by dying and losing a bunch of progress.

**2: Workbench crafting.** Cut down a tree and make yourself a workbench, then a few specialized tools to hang on it. This unlocks:
* Soup pots (soup will never go bad when boiling)
* Food preservation (pickled foods and alcohol or salt preserved foods never go bad in a vessel). Alcohol is also very useful for wound sterilization.
* Fishing and traps
* A pre-fab softwood structure
* Composting, which greatly speeds up farming

Additionally, there’s likely going to be a third stage to progression: metalworking. It’ll likely include copper (sailing from the shores to find islands with copper deposits) and meteoric iron (a meteor landing randomly during meteor showers). It’ll also likely include free building, or at least much more customizable and larger homes.
